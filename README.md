## About me

I build practical data analytics projects covering sales, inventory, customer behavior and operational reporting. My work focuses on using **Excel, SQL Server and Power BI** to prepare data, model relationships, track key metrics and communicate findings clearly.

- **Focus:** Business intelligence, SQL analysis, data modeling and interactive dashboards.
- **Domains:** Telecom, retail, e-commerce and operations.
- **Approach:** Data quality checks → SQL analysis → DAX measures → visual reporting.
